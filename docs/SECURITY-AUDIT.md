## 2. Authorization & Multi-Tenant Data Isolation (RBAC)

CMRG Survey enforces strict role-based access control across five permission tiers:

1. **Central Administrator (`ADMIN`)**:
   - Full server management, user provisioning, global exports, and audit access.
2. **Project Manager (`PROJECT_MANAGER`)**:
   - Create, edit, and archive projects; assign supervisors; publish questionnaires.
3. **Field Supervisor (`SUPERVISOR`)**:
   - Monitor assigned field teams; review, approve, or reject submissions; inspect GPS traces.
   - Forbidden from administrative user management or project deletion.
4. **Field Enumerator (`ENUMERATOR`)**:
   - Download assigned questionnaires; record interviews 100% offline; synchronize to server.
   - Forbidden from viewing submissions of other enumerators or accessing other projects.
5. **Data Analyst (`DATA_ANALYST`)**:
   - Read-only submission views and data exports (CSV, Excel, JSON). Forbidden from form modifications.

## 3. Data Integrity & Idempotent Synchronization

- **Duplicate Elimination**: Every submission record generated by mobile enumerators or Web Collect carries a unique `client_submission_id` (UUID v4).
- **Idempotency Guarantee**: Submitting the same batch multiple times (due to intermittent network drops) returns success without inserting duplicate database rows.
- **Deduplication on Boot**: `backend/db.ts` automatically filters and deduplicates all stored submissions on startup.

---

## 4. Encryption & Network Security

- **In-Transit Protection**: TLS 1.3 encryption enforced on all API routes and mobile synchronization channels.
- **At-Rest Protection**: Local SQLite database encrypted on device storage; media files stored in isolated directories.
- **Environment Secrets**: All private keys and passwords are systematically skipped in AI Studio sandbox and configured via automated VS Code Copilot script (`npm run keys:generate`) for production deployment. Zero hardcoded credentials in source control.
- **Zero Third-Party Telemetry**: Zero external analytics tracking, advertising SDKs, or cloud vendor tracking scripts.

---

## 5. Audit Logging Architecture

Every security-sensitive operation is recorded with actor username, timestamp, role, IP address, and operation summary in the `AuditLog` table:
- User login / logout
- Failed authentication attempts
- Form creation, editing, and publishing
- Submission reception and supervisor approvals
- Data export events
- Mobile device registration and pairing
